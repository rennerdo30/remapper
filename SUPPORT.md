# Support

## Where to Get Help

- Questions and usage help: open a GitHub Discussion or issue
- Bug reports: use the bug report issue template
- Security concerns: follow [SECURITY.md](SECURITY.md)

## What to Include

When asking for help, include:

- OS and version
- Remapper version (`remapper --version`)
- Reproduction steps
- Relevant logs (`RUST_LOG=debug` output if possible)
- Example config snippet (redact personal info)
