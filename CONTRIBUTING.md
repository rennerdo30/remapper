# Contributing

Thanks for contributing to Remapper.

## Getting Started

1. Fork the repository.
2. Create a branch from `master`.
3. Make focused changes with tests.
4. Open a pull request.

## Local Setup

```bash
git clone https://github.com/rennerdo30/remapper.git
cd remapper
cargo check
cargo test
```

## Development Guidelines

- Keep changes scoped and reviewable.
- Add or update tests for behavior changes.
- Update docs when user-facing behavior changes.
- Prefer clear commit messages.

## Pull Request Checklist

- [ ] Code builds with `cargo check`
- [ ] Tests pass with `cargo test`
- [ ] Docs were updated if needed
- [ ] PR description explains motivation and approach

## Reporting Issues

Use the issue templates for bug reports and feature requests.
Include reproduction steps, logs, and environment details when possible.

## Conduct

By participating, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
